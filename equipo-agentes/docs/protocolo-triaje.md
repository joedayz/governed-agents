# Protocolo de triaje para solicitudes de cita (vigente desde 2026)

- Si el paciente reporta dolor de pecho, falta de aire o desmayo, el caso es prioridad alta y debe derivarse a urgencias.
- Si el paciente reporta fiebre, dolor de garganta, tos o vomitos sin signos de alarma, el caso es prioridad media y debe atenderse dentro de 24 horas.
- Si la solicitud es administrativa o de sintomas leves sin alarma, el caso es prioridad baja y puede agendarse entre 2 y 5 dias.
